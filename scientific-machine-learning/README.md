# scientific machine learning

Study the mathematics and computational implementation of learning methods for scientific problems. This area integrates the former scientific-ml repository into matematications.

- [Physics-guided learning](physics-guided-learning/README.md)
- [Differentiable programming](differentiable-programming/README.md)
- [Inverse problems](inverse-problems/README.md), including [parameter identification](inverse-problems/001-parameter-estimation/README.md)
- [Neural ODEs](neural-odes/README.md)
- [Neural operators](neural-operators/README.md)
- [Data assimilation](data-assimilation/README.md)
- [Probabilistic modeling](probabilistic-modeling/README.md)

Method-focused paper reproductions live in [paper-reproductions](../paper-reproductions/README.md). Mathematical prerequisites, uncertainty propagation and optimization are shared with the rest of matematications; link to their canonical studies. Independent multi-model comparative investigations belong in [metron](https://github.com/gustavobernardo1/metron).

All initial studies are planned, not completed. Follow the root [AGENTS.md](../AGENTS.md) and [study template](../templates/study-template.md).
