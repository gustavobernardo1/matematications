# Matemática Computacional

Algoritmos numéricos, otimização matemática e quantificação de incertezas por meio de investigações computacionais reprodutíveis.

**Estado:** estrutura inicial; estudos planejados, não concluídos.

## Áreas de estudo
- [Álgebra linear numérica](numerical-linear-algebra/README.md): condicionamento, fatorações e métodos de solução.
- [Análise numérica](numerical-analysis/README.md): aproximação, discretização, estabilidade e erro.
- [Sistemas dinâmicos](dynamical-systems/README.md): modelos em espaço de estados, integração e estabilidade.
- [Otimização](optimization/README.md): otimização linear, convexa, não linear e estocástica.
- [Probabilidade](probability/README.md): variáveis aleatórias, amostragem e dependência.
- [Quantificação de incertezas](uncertainty-quantification/README.md): sensibilidade, propagação e calibração.
- [Experimentos computacionais](computational-experiments/README.md): benchmarks transversais e reprodutibilidade.
- [Referências](references/README.md): leituras selecionadas.

## Fluxo de trabalho
Problema → teoria direcionada → exercício independente → implementação → comparação com referência → validação → transferência.

Comece pelo [planejamento](ROADMAP.md) e pelo [modelo de estudo](templates/study-template.md). Assistentes de IA seguem [AGENTS.md](AGENTS.md).

Use Python 3.11+ e um ambiente virtual. Instale as ferramentas básicas com `python -m pip install -r requirements.txt`. Dependências específicas e versões devem constar nas instruções de reprodução de cada estudo.
