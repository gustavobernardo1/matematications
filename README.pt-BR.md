# matematications

Explorações em matemática e computação — uma coleção voltada ao aprendizado de ideias matemáticas, demonstrações, métodos, experimentos numéricos e aprendizado de máquina científico.

**Estado:** estrutura inicial de estudos; sem pesquisas ou experimentos concluídos alegados.

## Escopo

Compreender, deduzir, implementar e validar métodos matemáticos. Experimentos e reproduções focados em métodos ficam aqui; avaliações comparativas independentes de modelos pertencem ao [metron](https://github.com/gustavobernardo1/metron), e investigações de descoberta sobre conjecturas abertas pertencem ao [conjectura](https://github.com/gustavobernardo1/conjectura).

As áreas de estudo do antigo scientific-ml foram incorporadas a este repositório. Consulte o [registro de migração](MIGRATION.md).

Problema → teoria direcionada → exercício independente → implementação → comparação com referência → validação → transferência.

Consulte as [direções de estudo](ROADMAP.md), o [modelo de estudo](templates/study-template.md) e as [instruções para agentes](AGENTS.md).

Python 3.11+; instale as ferramentas básicas em ambiente virtual com `python -m pip install -r requirements.txt`. Registre dependências e versões específicas nas instruções de reprodução.
