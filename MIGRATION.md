# Integration of scientific-ml

Source: [scientific-ml at 7078cb8](https://github.com/gustavobernardo1/scientific-ml/tree/7078cb8595a517e1c4f0c921e7e4c3277db7dba3).

The seven scientific ML topic areas and the parameter-estimation study were imported into scientific-machine-learning/. Paper reproductions are now a cross-disciplinary root area. Relative links to the shared template have been adjusted. The former benchmark placeholder is superseded by the method-focused computational experiments area and the independent metron repository. The shared AGENTS, study template, requirements and tool configuration are consolidated at the root; the study roadmaps are combined. Both language versions of the root README are updated. Existing mathematical study paths remain intact to preserve links.

The source repository and original commits remain intact; this is a content integration, not a Git history merge. No experimental implementation or scientific result was present in the imported initial studies. No research results have been generated during migration.
